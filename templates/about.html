About the project

Student Placement Prediction System

SMART HIRE is an end-to-end AI/ML web application for employability prediction, role recommendation, and hiring pattern analysis.

How Predictions Are Made

The project generates a realistic synthetic dataset of student profiles with academic, skill, experience, risk, and domain-interest features. The placement model solves a binary classification problem, while the role model solves a multiclass classification problem across modern tech roles.

Both tasks use a preprocessing pipeline with numeric scaling and categorical one-hot encoding. Multiple algorithms are trained and compared, then the best model is saved as a reusable sklearn pipeline.

Feature selection

SelectKBest + ExtraTrees

Filter scores and tree importances are combined to show selected, dropped, and top-ranked features.

Readiness score

Weighted 0-100 score

CGPA, aptitude, programming, test performance, interview readiness, projects, internships, certifications, and resume strength are scored with penalties for risk factors.

Batch prediction

CSV in, CSV out

Bulk student profiles are validated against the same feature contract used by the manual prediction form.
